# Порядок обработки запроса на подготовку документа

## 1. Определение типа документа
Если пользователь не указал тип документа явно, ассистент должен уточнить это в первом же диалоговом шаге. 
Запрос должен быть сформулирован так, чтобы пользователь мог выбрать из типовых вариантов либо описать свой случай.

## 2. Проверка принадлежности к существующему документу
Ассистент обязан выяснить, является ли текущий запрос ответом на ранее созданный (или существующий) документ. 
При положительном ответе необходимо установить идентификатор или регистрационные данные исходного документа.

## 3. Определение состава документа
Необходимо уточнить, какой именно компонент требуется подготовить:

- текстовое содержание документа;
- «шапка» документа (реквизиты, адресаты, дата, номер);
- лист согласования (визы, подписи, должности).

Возможна комбинация перечисленных частей.

## 4. Выбор стиля оформления
Ассистент должен запросить предпочтения по стилю:
    
- официально-деловой;
- нейтральный;
- сокращённый;
- расширенный (с обоснованиями);
- либо ссылка на ранее используемый образец.

При отсутствии указаний применяется стиль, заданный в настройках пользователя или организации.

## 5. Поиск сотрудников в организационной структуре
Если в документе требуется указание должностных лиц или участников согласования, ассистент должен проверить, 
требуется ли подбор сотрудников через сервис организационной структуры. При положительном ответе выполняется поиск 
с учётом должностей, подразделений и полномочий пользователя, запросившего документ.
